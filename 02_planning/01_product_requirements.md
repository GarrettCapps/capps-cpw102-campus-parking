# Product Requirements

**Project:** Campus Parking Helper

**Team members:** Garrett Capps

**Date:** 30 September 2026

## User and problem

Who is the user? Drivers who are paying for parking at the CPTC parking lot

What problem does the user have? Currently, there is no automated way to determine how much the driver must pay for a given parking duration

## Goal

Our program will help the user: Determine how much they will need to pay for parking for a given duration

## Requirements

Write three things the program must do. Make each one specific enough to test.

1. The program must know the hourly rate of parking
2. The program must prompt the user for how long they will be parked in terms of hours and partial hours
3. The program must determine the estimated cost of parking given the duration
4. The program must inform the user of the price of parking

## Not included

What will this version **not** do?

1. The program will not have an adjustable hourly rate for parking
2. The program will not handle transactions

## Success

We will know the product works when: it is able to accurately determine the cost of parking for any duration given in hours and partial hours and clearly communicate this to the user
